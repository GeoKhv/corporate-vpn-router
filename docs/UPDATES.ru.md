# Обновления и откат

Встроенный канал Sparkle предлагает **0.3.24 by MichaelTG**. Чистая и «Красная» сборки 0.3.25 доступны для ручной установки. Для обеих нужен Mac с Apple Silicon и macOS 26+. [Скачать сборки](../README.md) · [Лента Sparkle](https://github.com/GeoKhv/corporate-vpn-router/releases/download/update-channel/appcast.xml)

## Как обновляется приложение

В окне Router нажмите **«Проверить обновления»**. Автоматическую проверку можно включить или выключить в меню «Обновления». Загрузка и установка требуют подтверждения **«Загрузить и установить»**. Во время загрузки доступна отмена в меню.

Sparkle проверяет подписи пакета и ленты Ed25519. Router сохраняет резервную копию, завершает рабочий сеанс и проверяет очистку маршрутов у помощника. После подтверждения очистки Sparkle заменяет приложение по исходному пути и запускает его заново. Для нового подключения потребуется MFA. Личный VPN продолжает работать.

Рабочий список, привязка шлюза, настройки, сертификатные материалы и таблица адресов хранятся отдельно в `~/Library/Application Support/Corporate VPN Router`. Установка поверх Router сохраняет эти данные. «Красная» загружает свой стартовый профиль при отсутствии рабочего списка. При утверждении новых разрешений macOS может показать отдельный запрос администратора.

## Откат

1. Отключите рабочие маршруты и завершите Router.
2. Найдите предыдущую копию в `~/Library/Application Support/Corporate VPN Router/UpdateBackups/<version>-<UUID>/`. Файл `restore.json` содержит исходный путь. Для ручной установки используйте копию `.app`, которую сохранили перед заменой.
3. Верните прежний `.app` в исходную папку установки и откройте его оттуда. Данные в Application Support и настройки помощника сохраните. При необходимости используйте «Доступы… → Ещё → Вернуть предыдущие правила…» и подтвердите разрешения.

Sparkle предлагает только версии с большим номером сборки. Для выпуска исправления используйте новый номер.

## Подписи

Code signing приложения — ad hoc. Для первой установки macOS может запросить «Всё равно открыть». Ed25519 защищает доставку через Sparkle. Публичный ключ хранится в `packaging/updates/public-key.txt`, закрытый — в Keychain машины выпуска. Подпись автора в интерфейсе не участвует в сравнении версий. [Упаковка и проверка канала](BUILDING.ru.md)

## Защищённая резервная копия ключа

В обычном интерактивном Terminal выполнить `scripts/update-key-backup.sh export /path/offline/cvr-signing-key.encrypted.json`. Ввести отдельную длинную парольную фразу. Утилита читает ключ непосредственно из Keychain, шифрует AES-256-GCM с PBKDF2-HMAC-SHA256 (600000 итераций, случайная соль), проверяет расшифрование в памяти и пишет только шифротекст с правами 0600. Ключ и пароль не попадают в argv, stdout или незашифрованный файл. Хранить копию офлайн, пароль отдельно. `--self-test` проверяет круговой проход, неверный пароль и подмену метаданных на случайном тестовом ключе.

Восстановление на машине выпуска: `scripts/update-key-backup.sh restore /path/cvr-signing-key.encrypted.json`. Отличающийся существующий ключ не заменяется. Сверить публичный ключ с репозиторием. Создание реальной офлайн-копии требует участия владельца и выбранного им пароля/носителя; автоматический тест не является резервной копией производственного ключа. При потере ключа ad-hoc-сборка с обязательной Ed25519-проверкой потребует ручного доверенного распространения новой стартовой версии.
