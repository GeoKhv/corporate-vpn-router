# Доверие к корпоративному шлюзу

Beta читает настроенный сайт из подписанного официального trac в защищённом системном каталоге. Сверяет его подпись Apple Developer ID / команду производителя, права на файлы и каталоги, единственный сохранённый публичный отпечаток и имя сертификата. Требует один сайт, Idle, согласованность DNS с адресом шлюза, IP в SAN сертификата и успешную проверку цепочки TLS. Первичное получение публичной цепочки не отправляет данные CCC или MFA.

До первого входа пользователь подтверждает привязку сайта, IP и SHA-256 CA. Любое несовпадение с сохранённой привязкой или официальным pin закрывает соединение. Не устанавливаются сертификаты в Keychain, не копируются закрытые ключи и данные входа официального клиента. Ошибки имени, дат, цепочки и редиректы не разрешают повторить запрос в небезопасном режиме. При плановой ротации подтвердите изменение у своего администратора; автоматической кнопки «доверять новому pin» нет.
