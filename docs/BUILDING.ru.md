# Сборка и публикация 0.3.19

## Два набора исходников

Этот репозиторий содержит приложение AppKit, Python-контроллер, помощник маршрутов, тесты и изменения сторонних компонентов. Полный исходный комплект IPsec с закреплёнными зависимостями Cargo приложен к [релизу 0.3.19](https://github.com/GeoKhv/corporate-vpn-router/releases/tag/v0.3.19-ipsec-test): `Corporate-VPN-Router-0.3.19-IPsec-source.zip`. Контрольные суммы — [release manifest](releases/0.3.19.json).

Публичный Git не содержит личный профиль, приватные ключи, настройки рабочих доменов или журналы получателя. Для стартового комплекта нужен отдельно проверенный профиль развёртывания. Обычный ZIP обновляет уже настроенное приложение.

## IPsec-модуль

На Apple Silicon с Xcode Command Line Tools и Rust 1.100.0 распакуйте исходный ZIP, перейдите в `source/snx-rs` и выполните `./build-router.sh`. Скрипт использует vendored-зависимости в offline-режиме. Результат — `target/release/cvr-ipsec`. Закреплённые upstream-коммиты, лицензии и ограничения перечислены в [README модуля](../ThirdParty/ipsec-bridge/README.md). Секреты не передаются через аргументы запуска или файлы конфигурации.

## Приложение

Текущий путь упаковки — `scripts/build-update.py`. Он использует проверенное предыдущее приложение как базу для встроенных Python, SOCKS, sing-box и Sparkle. Это не автономная сборка всего runtime с нуля. `scripts/build.sh` относится к прежней beta-упаковке и не является рецептом текущего релиза.

Пример без профиля организации (все пути замените своими):

```sh
python3 scripts/build-update.py \
  --base-app '/path/to/Corporate VPN Router TUN Trial.app' \
  --sparkle '/path/to/Corporate VPN Router TUN Trial.app/Contents/Frameworks' \
  --output '/path/to/new-output' \
  --version 0.3.19 --build 3019 \
  --ipsec-bridge '/path/to/source/snx-rs/target/release/cvr-ipsec'
```

Каталог вывода должен быть новым. Без `--ipsec-bridge` сборщик намеренно удаляет унаследованный тестовый IPsec-модуль. Параметры `--site-pin`, `--deployment-desktop` и `--private` требуют отдельной проверки состава: они могут включить данные организации. Не копируйте эти значения из пользовательских журналов. Опубликованный текущий пакет требует macOS 26+, даже если Swift-компонент и Sparkle допускают более раннюю ОС.

## Проверки без рабочего подключения

Из корня репозитория:

```sh
python3 Tests/Selective/test_ipsec_bridge.py
python3 Tests/Selective/test_support_report.py
bash Tests/DiagnosticPresentation/run.sh
bash scripts/test-route-helper.sh
bash scripts/test.sh
```

Тесты используют синтетические данные, временные каталоги и локальные серверы. AppKit-тест буфера требует доступной сессии macOS и использует отдельный именованный буфер. Для некоторых сетевых fixtures и системных API песочница среды разработки требует отдельного разрешения. Другие сценарии в Tests могут требовать путь к собранному Engine — читайте их параметры перед запуском. Успешные тесты не заменяют вход и проверку реальных сайтов на Mac получателя.

Для исходного Rust-комплекта применяются fmt, clippy и тесты поставляемого workspace; два теста системного Keychain при проверке выпуска пропущены, чтобы не изменять пользовательское хранилище. Проверки пакета: `scripts/audit-update.py`, `scripts/audit-macos-bundle.py`, подписи, архитектура, права executable и зависимости после распаковки ZIP. Сначала изучите `--help` соответствующего скрипта.

## Публикация

1. Сверьте VERSION, версию и build пакета, контрольную сумму, состав и лицензии; проверьте отсутствие секретов и пользовательских данных.
2. Опубликуйте неизменяемые ZIP, SHA-256, подпись, исходники IPsec и инструкцию в отдельном GitHub prerelease. Старые артефакты и теги не перезаписывайте. Текущий выпуск: `v0.3.19-ipsec-test`.
3. Для нового STARTER используйте отдельный `starter-v<версия>` и точные имена из [AGENTS.md](../AGENTS.md). Сравните настройки с предыдущим согласованным STARTER.
4. Скачайте ZIP без авторизации, сверьте SHA-256 и подпись. Изолированно проверьте распакованный пакет и экспорт.
5. Обновление канала Sparkle — отдельное действие: подпишите пакет и ленту, сохраните прежнюю ленту для отката и проверьте обнаружение новым и предыдущим клиентом. См. [UPDATES](UPDATES.ru.md).

GitHub Actions для выпуска не используются. Действующий VPN и установленное приложение не меняются только ради сборки. Ключ Ed25519 остаётся в Keychain машины выпуска. Ad hoc codesign не означает Developer ID или нотариализацию Apple.
