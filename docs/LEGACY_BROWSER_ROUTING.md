# История браузерной маршрутизации

Этот документ описывает предыдущие способы подключения браузеров. **Для приватного экспериментального режима 0.3.0-alpha.1 расширение браузера и конфигурационный профиль Chrome не требуются.** Публичная beta.6 при этом по-прежнему использует свой профиль Chrome.

## Как развивалось решение

- **Ранние версии:** маршрутизация рабочих сайтов через корпоративный SOCKS5 и браузерный прокси. В отдельных сценариях применялось расширение [Smart Proxy Route Helper](https://github.com/GeoKhv/smart-proxy-route-helper), управляющее правилами Work/Life в Chrome.
- **0.2.0-beta.5:** локальный VPN-транспорт и профиль Chrome с PAC. Для изменения списка доменов требовалось обновлять профиль.
- **0.2.0-beta.6 (публичный релиз):** постоянный локальный HTTP/CONNECT-маршрутизатор и однократно подтверждаемый профиль Chrome. Правила меняются в приложении без переустановки профиля; само расширение не требуется.
- **0.3.0-alpha.1 (приватный прототип):** выборочная маршрутизация корпоративного TCP-трафика и DNS на уровне macOS. Проверены обычные Chrome, Safari, Яндекс Браузер и работа установленного OWA Widget на одном Mac с Sota — без настройки отдельных браузеров.

Подробности старого режима: [ARCHITECTURE.md](ARCHITECTURE.md). Установка именно опубликованной beta.6: [COLLEAGUES.ru.md](COLLEAGUES.ru.md).

## О расширении Smart Proxy Route Helper

Расширение остаётся самостоятельным проектом и может использоваться там, где выбран браузерный способ управления прокси; **оно не является обязательным компонентом нового сетевого режима**.

В версии расширения 0.4.1 была выявлена проблема синхронизации независимых изменений Work/Life между устройствами. Не рекомендуем переносить единственный рабочий список в эту версию без резервной копии. Актуальный статус проверяйте в [релизах расширения](https://github.com/GeoKhv/smart-proxy-route-helper/releases). Эти ограничения относятся к расширению, а не к универсальной маршрутизации alpha.1.

OWA Widget — отдельное стороннее приложение для календаря, **не маршрутизатор**. Оно упоминается как пример приложения, которое смогло работать через экспериментальный режим.
