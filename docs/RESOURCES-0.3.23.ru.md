# Обновление до 0.3.23

В Router нажмите «Проверить обновления», затем «Загрузить и установить». Обновление завершает текущий рабочий сеанс. После перезапуска нажмите «Подключить» в меню Router. Если необходимы новые разрешения, macOS покажет список перед подтверждением.

**Новые сайты.** В ZIP входят точные правила HTTPS (TCP 443) для testrwa.alfabank.ru и administrator.testrwa.alfabank.ru. При первом подходящем подключении Router сверяет их с текущим профилем. Покрывающее правило с поддоменами или любым TCP продолжает работать. Если у точного имени уже есть другие порты или алиас, они сохраняются. Отдельная отметка применения позволяет позднее изменить или удалить добавленные правила. Прежняя отметка SSH/Lens учитывается отдельно. Исключения для входа и ограничения существующего дерева на самом целевом имени имеют приоритет: если дерево исключает 443, изменение его охвата требует ручного решения.

**После обрыва.** Если Router удерживает защитные маршруты, кнопка «Подключить» восстанавливает сеанс с действующими разрешениями. Отложенный список остаётся на диске. Если хотите применить его сразу, штатно отключите рабочие маршруты и снова подключитесь. Отмена системного подтверждения или ошибка записи сохраняет список для повторной попытки. Если до или во время подтверждения вы внесли другие правки в черновик, после применения в нём останутся эти изменения.

**Короткие имена.** Поисковые суффиксы нужны редактору для поиска полного имени через корпоративный DNS в разрешённой области. В «Рабочие сайты…» вставьте короткое имя, нажмите «Разобрать адреса…», проверьте полное имя, порт и алиас, затем добавьте в черновик и примените. Для поиска нужен подключённый туннель. Если информации для поиска нет, введите полное имя узла вручную и отметьте «Короткое имя». Обычное приложение сможет использовать сохранённый алиас после подключения с применёнными правилами. Для HTTPS сертификат должен подходить к имени в ссылке.

**Одна приёмка для коллеги.** Обновитесь и подключитесь из меню Router. Откройте привычные подключения в SSH и Lens, затем оба HTTPS-адреса из первого абзаца про новые сайты. В редакторе добавьте одно ранее не настроенное короткое имя указанным выше способом и откройте его в обычном приложении после применения правил.

**Проверки выпуска.** Оба дефекта воспроизведены на Mac в AppKit версии 0.3.22 с отдельным профилем и локальными процессами вместо корпоративного транспорта. На 0.3.23 проверены сохранение удерживаемого контроллера при повторном входе, отмена и ошибка применения с последующим успешным повтором, редактирование во время подтверждения, повторная загрузка черновика при открытом и закрытом редакторе. Миграция проверена на копии профиля предыдущей установки и отдельно на правилах с любым TCP, алиасом и покрывающим деревом. На контролируемом транспорте проверены обмен данными по TCP 22/6443, отказ для запрещённого порта и блокировка при потере транспорта. Эти проверки не подтверждают вход в корпоративный SSH, Lens или веб-сервис.

**Откат.** Отключите рабочие маршруты и завершите Router. Верните предыдущий .app из резервной копии Sparkle в исходную папку установки. Если нужно отменить изменения правил, в редакторе загрузите «Предыдущие правила» либо импортируйте резервную копию профиля, проверьте список и подтвердите применение. Сохраните текущую таблицу Selective/domain-map.json. [Подробности о резервной копии](UPDATES.ru.md).
