# Начало работы на Mac

1. Нужны Apple Silicon, macOS 13+, обычный Google Chrome и настроенный корпоративный сайт в официальном клиенте Check Point. Скачайте Mac-архив со [страницы релиза](https://github.com/GeoKhv/corporate-vpn-router/releases/tag/v0.2.0-beta.5), распакуйте и откройте **Corporate VPN Router.app**. При обновлении завершите прежний Router. Двойной щелчок устанавливает приложение в «Программы» текущего пользователя. При входе в macOS стартует только значок VPN. Архив подписан на уровне приложения ad hoc, без Developer ID и нотарификации. Если политика Mac блокирует запуск, согласуйте установку с ИТ; отключать Gatekeeper не нужно.
2. Откройте значок VPN → **Рабочие сайты**. Получите приватный файл профиля у коллеги по внутреннему каналу и нажмите «Импорт профиля…», либо добавьте полные доменные имена вручную. Для каждого выберите «Только это имя» или «Имя и все поддомены». Внесите точные адреса шлюза и провайдера входа в «Доступ до входа». Они используют обычный маршрут, даже внутри рабочего суффикса. По умолчанию рабочий HTTPS разрешён на 443. «Проверить маршрут» показывает решение по черновику, не посылая запрос.
3. Нажмите **Приложение…** и прочитайте область применения. В Системных настройках → Основные → Управление устройством откройте загруженный **Corporate VPN Router · Chrome** и установите его. Названия разделов различаются между версиями macOS. Затем нажмите «Проверить статус». В обычном Chrome откройте chrome://policy, нажмите перезагрузку политик: ProxySettings должна быть обязательной, без ошибок, с ProxyPacMandatory=true. ИТ-политики и другой системный прокси требуют отдельного согласования. Профиль меняет только Chrome текущего пользователя, включая другие его браузерные профили. Расширение для этого режима не нужно. Если оно установлено, можно выключить его в chrome://extensions, не удаляя и не очищая его данные. При правке списка подтвердите замену профиля в macOS; до замены действуют прежние правила.
4. В основном окне выберите **Ключ доступа в браузере** либо **Код + пароль**, затем «Подключить». Один раз подтвердите доверенный сайт/CA; сертификат в macOS не устанавливается. Активный официальный VPN требует отдельного согласия на переключение. Sota оставьте в обычном режиме. Диагностика «Проверить HTTPS» делает реальный запрос через SOCKS. Сравните рабочий и обычный сайт в новых вкладках Chrome.
5. **Отключить** завершает только туннель. Рабочие адреса всё ещё направляются в SOCKS, пока профиль активен. Обычные адреса идут напрямую по системному маршруту. После сна или отказа нужен новый вход. Ошибка самого обязательного PAC может остановить и обычные страницы Chrome. Другие программы, прямые IP, альтернативные браузеры, существующие соединения и сторонние политики не покрываются этим правилом.

**Вернуть управление.** Сначала подготовьте сохранённое расширение и его Work-маршрут. В «Рабочих сайтах» нажмите **Расширение…**. Router проверяет идентификатор, UUID и содержимое своего профиля и просит macOS удалить его. Чужую конфигурацию он не записывает. Включите прежнее расширение, проверьте его прокси и новую рабочую вкладку до обычной работы. Удаление профиля вне Router или отключение расширения в режиме расширения может открыть прямой путь. После смены режима обязательно проверьте chrome://policy и поведение браузера. Если macOS отказала в снятии, удалите именно пользовательский профиль Router через «Управление устройством» и перепроверьте статус.

**Обновление, откат и удаление.** «Обновления…» открывает выпуски GitHub; скачайте новый архив, завершите текущую версию и откройте новую. «Вернуться к beta.4…» проверяет подпись локальной копии beta.4 и возвращает управление расширению. Если копии нет, сначала верните управление расширению, затем установите [опубликованную beta.4](https://github.com/GeoKhv/corporate-vpn-router/releases/tag/v0.2.0-beta.4). «Удалить Router…» снимает собственный профиль, удаляет собственный login item и перемещает приложение в Корзину. Приватные профили, сохранённые логины, pin и копии остаются в Application Support для восстановления; удаляйте их отдельно лишь если они больше не нужны.
