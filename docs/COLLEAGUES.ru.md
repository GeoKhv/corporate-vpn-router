# Установка и работа с Router

## Установка на новом Mac

1. На [странице проекта](../README.md) выберите «Чистую» или «Красную» сборку. Нужны Apple Silicon, macOS 26+ и официальный Check Point с настроенным сайтом организации.
2. Скачайте и распакуйте ZIP. Откройте приложение и нажмите **«Установить и открыть»**. Далее запускайте установленную копию из `~/Applications`.
3. Сборка подписана ad hoc. Если macOS блокирует первый запуск, проверьте, что ZIP скачан с официальной страницы проекта. Используйте штатное **«Системные настройки → Конфиденциальность и безопасность → Всё равно открыть»** для этого приложения.
4. В чистой сборке откройте **«Доступы…»** и сохраните хотя бы один рабочий адрес. В «Красной» уже есть рабочий профиль. При первом применении правил или подключении подтвердите список разрешений помощника в диалоге macOS.

## Подключение

Нажмите **«Подключить»** и следуйте подписям полей. Router заново запрашивает MFA при новом входе. «Ключ доступа в браузере» доступен для совместимых SSL-профилей. Для поддержанного сценария IPsec используйте код и пароль.

Если официальный Check Point уже подключён, Router предложит подтвердить переключение. Для нового шлюза следуйте штатной проверке идентичности. Если сертификат или закреплённая идентичность не совпали, сверьте сайт с настройками организации. [Проверка сертификатов](CERTIFICATES.ru.md)

## Правила доступа

В **«Доступы…»** вставьте полное имя, ссылку, `user@host` или `host:порт` и нажмите **«Разобрать»**. Выберите нужные строки и назначение, проверьте короткое имя и нажмите **«Добавить»**, затем **«Сохранить»**. Для дерева доменов используйте `*.example.org`. Для правки существующего правила выделите его и нажмите **«Изменить»**.

Суффиксы поиска помогают найти полное имя при активном рабочем сеансе. Обычное приложение сможет использовать сохранённый алиас после применения правил. Для HTTPS имя в ссылке должно подходить к сертификату.

Если рабочий сеанс активен, сохранённые правила ждут следующего полного подключения. При обрыве Router удерживает защитные маршруты и восстанавливает соединение с действующим списком. Отложенные правила применятся после явного отключения и нового подключения.

## Обновление и откат

Для обновления до 0.3.25 с 0.3.24 используйте Sparkle. Более ранним версиям сначала предлагается 0.3.24. После установки 0.3.24 подключитесь, чтобы применились прежние рабочие правила, затем снова проверьте обновления.

Для ручного обновления скачайте ZIP, отключите рабочие маршруты, завершите Router и откройте скачанное приложение. Сохраните копию прежнего `.app`. Профиль уже настроенного Router сохраняется.

Для выпусков канала Sparkle в Router нажмите **«Проверить обновления» → «Загрузить и установить»**. После перезапуска подключитесь заново. Sparkle сохраняет копию прежнего приложения. Чтобы откатиться, отключите рабочие маршруты, завершите Router и верните резервную копию в прежнюю папку установки. [Подробности об обновлениях и резервных копиях](UPDATES.ru.md)

## Если не подключается

Откройте **«Диагностика…»** из окна Router или меню. В ней отдельно показываются проверка шлюза, авторизация, туннель, DNS и доступ по HTTPS к одному указанному адресу. При необходимости нажмите **«Сохранить и открыть логи…»** и передайте полученный отчёт для разбора. После успешного сохранения сам файл также доступен для вставки через Cmd+V.
