# Переход, эксплуатация и возврат

## Возврат с beta.3 на beta.2

Выберите «Завершить» в меню Router, затем откройте **Restore beta.2.command** из распакованного архива. Скрипт проверяет подпись локальной резервной копии опубликованной beta.2 и устанавливает приложение обратно. Сохраняются логины, Work/Life, Sota, pin и настройки Chrome. При отсутствии копии завершите Router и установите приложение из [предыдущего Mac Beta-релиза](https://github.com/GeoKhv/corporate-vpn-router/releases/tag/v0.2.0-beta.2).

## Возврат к схеме до beta.1

Перед миграцией сохраните экспорт правил и локальных endpoint Chrome, прежнее приложение и его login item. Назначение каждого правила важнее числа строк: штатный импорт расширения объединяет эквивалентные www-имена. Не заменяйте общее хранилище работающего браузера файлом другого профиля.

Проверьте сначала Work, затем Life, затем отключите туннель и откройте новые соединения с обеих сторон. Work должен перестать открываться; Life — продолжать работать. Старые помощники отключайте только после проверки, сохранив их LaunchAgent и конфигурацию. Нельзя одновременно держать два контроллера прокси Chrome.

Чтобы вернуться, закройте Beta через «Завершить». Выключите управление прокси у новой копии расширения, включите сохранённую магазинную версию/прежний endpoint и восстановите прежние login items и приложение из копии. Если прежняя схема требует корпоративного VPN официального клиента, подключитесь в нём обычным способом. При удалении Beta удалите только её login item com.geokhv.corporate-vpn-router.menu и само приложение. Не удаляйте папку Application Support, если там хранятся копии для отката.
