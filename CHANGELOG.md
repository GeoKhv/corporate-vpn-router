# История изменений

## 0.3.26 by MichaelTG · «Красная» · build 3026

В стартовый рабочий профиль добавлены Superset и «Метрика» с короткими именами и разрешением HTTPS на TCP 443. При установке поверх прежней версии Router предлагает добавить правила при подключении и сохраняет существующие разрешения.

## 0.3.25 by MichaelTG · build 3025

Чистая сборка и «Красная» с готовым профилем для первой установки. В чистой можно сохранить первый рабочий адрес из пустого редактора. Страница проекта показывает актуальные окна и обе ссылки для скачивания.

## 0.3.24 by MichaelTG · build 3024

Новый экран «Доступы» с предпросмотром списка адресов и правкой правил на месте. Обновлены меню и окно входа. [PR №4](https://github.com/GeoKhv/corporate-vpn-router/pull/4).

## 0.3.23 · build 3023 · 18 ноября 2026

При обрыве корпоративного транспорта Router может повторно войти с удерживаемыми маршрутами и сохранённым отложенным профилем. Применение предыдущего списка сохраняет более свежие изменения черновика при перезапуске. Обновление доставляет два точных HTTPS-адреса и учитывает уже покрытые назначения. [Инструкция и приёмка](docs/RESOURCES-0.3.23.ru.md).

## 0.3.22 · build 3022 · 18 ноября 2026

Выбор строки в таблице больше не меняет назначение кнопки «Добавить». Для правки, удаления и отмены есть отдельные действия. Редактор показывает охват и TCP-порты, разбирает несколько ссылок и поддерживает перенос правил между Mac. Подключение из меню поднимает главное окно. Поиск короткого имени использует DNS текущего корпоративного сеанса и явные алиасы.

## 0.3.21 · build 3021 · 18 ноября 2026

- Штатное обновление включает правило для точного имени `dfa-test-master1.moscow.alfaintra.net`, его короткого имени и портов 22 и 6443. При первом подключении Router применяет его в профиле, который уже охватывает этот сервер. Существующие порты сохраняются.
- Когда помощнику нужны новые разрешения, macOS запрашивает подтверждение. После успешной записи приложение продолжает подключение. Предыдущий список доступен для отката.

## 0.3.20 · build 3020 · 18 ноября 2026

- Для полного имени или дерева доменов можно задать TCP-порты. Отдельному серверу можно назначить короткое имя. Профиль прежнего формата сохраняет действующие ограничения.
- В меню Router откройте «Рабочие сайты…» для проверки конкретного адреса, изменения правила или импорта одного правила от коллеги. Изменения области доступа требуют подтверждения. Для обычного входа и проверки адреса права администратора не нужны.
- При потере корпоративного транспорта в активном сеансе Router держит рабочие IPv4/IPv6-маршруты и блокирует доступ по сохранённым адресам до повторного входа. Кнопка «Отключить рабочие маршруты» завершает эту защиту. Личный интернет остаётся доступен.

[Подробности и приёмка](docs/TCP-0.3.20.ru.md)

## 0.3.19 · build 3019 · 17 ноября 2026

- Общий запрос `password:` получает подпись соответствующего фактора выбранного шлюза. Конкретные динамические запросы сохраняются; отсутствующие подписи не сдвигают порядок факторов. Ответы MFA не сохраняются и не воспроизводятся.
- Диагностика HTTPS показывает проверяемый адрес и отдельную причину ошибки. Ограниченный GET заменяет HEAD. HTTP-ответ, включая отказ в доступе, подтверждает транспорт и TLS, но не права пользователя внутри сайта.
- Числовые результаты curl, HTTP и TLS включаются в отфильтрованный отчёт. Ошибка одного адреса не объявляется отказом всех рабочих сайтов.
- После успешного сохранения TXT-файл копируется в буфер для вставки Cmd+V и открывается. Отмена и ошибка записи не заменяют содержимое буфера.
- Исправлено копирование текстов лицензий при упаковке с файловой системы macOS с дополнительными атрибутами.

## 0.3.18 · build 3018

Удалён неиспользуемый запрос CCC ClientSettings после IPsec-авторизации, который шлюз отклонял. Адрес, DNS и параметры ESP берутся из аутентифицированного IKE. Правила доступа SOCKS и проверки сертификата остаются обязательными. Пользователь подтвердил на компьютере получателя вход по OTP и паролю и работу рабочих и внешних сайтов с внешним VPN.

## 0.3.17 · build 3017

Добавлен отдельный непривилегированный модуль IKEv1/IPsec через TCPT для проверенного отказа SSL Network Extender с кодом 205. До ввода секретов проверяются сертификат и подпись IKE. Модуль передаёт пакеты существующему ограниченному SOCKS и сам не изменяет системные маршруты. Браузерный вход в этом транспорте не реализован. В этом выпуске последующий запрос CCC ещё мешал завершению подключения; исправление — 0.3.18.

## 0.3.14–0.3.16

Добавлены поставляемая проверенная привязка альтернативного сайта и автоматический выбор поддержанного сайта при нескольких записях Check Point. Расширена отфильтрованная диагностика этапов и причин завершения SSL. Исправлен экспорт отчёта из изолированного Python приложения. Настройки рабочих сайтов перестали открываться автоматически при каждом входе.
