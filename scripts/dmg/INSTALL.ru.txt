Corporate VPN Router · Mac beta.6 · installer-fix.1

УСТАНОВКА
Дважды нажмите «Установить Corporate VPN Router» в этом DMG.
Приложение устанавливается в ~/Applications без администратора.
При обновлении сначала закончите рабочий сеанс и завершите Router через меню.
Работающий Router установщик не заменяет, VPN-сеанс не прерывает.
Прежняя копия сохраняется для отката; настройки и рабочие сайты не удаляются.
Существующий автозапуск сохраняется. Chrome и Sota не перезапускаются.
После запуска установленного Router извлеките DMG.

ПРОВЕРКА
Источник: https://github.com/GeoKhv/corporate-vpn-router/releases/tag/v0.2.0-beta.6
В папке загрузки выполните:
shasum -a 256 -c Corporate-VPN-Router-0.2.0-beta.6-macOS-arm64-installer-fix.1.dmg.sha256

РАЗРЕШЕНИЕ MACOS
Приложение и установщик подписаны ad hoc, без Developer ID и нотариализации.
Если macOS заблокировала «Установить Corporate VPN Router», после проверки
источника и SHA-256 откройте «Системные настройки → Конфиденциальность
и безопасность → Всё равно открыть» и подтвердите «Открыть».
Если отдельная блокировка относится к «Corporate VPN Router», разрешите
тем же способом именно его, затем откройте из ~/Applications.
Повторно устанавливать DMG после этого не нужно.
Не отключайте Gatekeeper и не снимайте карантин командами.
Если политика организации запрещает разрешение, установка не поддерживается.

ОШИБКИ
Сообщение содержит операцию, путь и системную причину. Сохраните его полностью.
Ошибка записи автозапуска отменяет замену приложения.
Сообщение «Приложение установлено» означает отдельную проблему запуска macOS.
Не удаляйте папку настроек для исправления ошибки.
Копию в /Applications сохраните в резервной папке после завершения Router;
установщик использует только ~/Applications.

ОТКАТ УСТАНОВКИ BETA.6
Завершите Router. В Finder откройте ~/Library/Application Support/Corporate VPN Router.
Выберите прежнюю rollback-<идентификатор>.app по времени и версии
в Contents/Resources/VERSION. Переместите текущую копию из ~/Applications
в резервную папку за пределами Applications. Скопируйте выбранную прежнюю
копию в ~/Applications с именем Corporate VPN Router.app и откройте её.
Путь автозапуска и данные остаются прежними. Откат к beta.5 с заменой профиля
Chrome выполняется отдельно через меню приложения.
